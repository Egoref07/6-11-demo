# Корочки.есть

Учебный проект на Next.js, React и TypeScript с PostgreSQL и Prisma.
Переработан на основе [polinaWebDev/demo-6-11](https://github.com/polinaWebDev/demo-6-11): исходники сгруппированы по назначению, функции и константы получили новые имена, обновлены импорты и команды.

## Что реализовано

- Главная страница с перенаправлением на вход.
- Регистрация, вход и выход, сообщения об ошибках полей.
- Создание и просмотр заявок, календарь выбора даты и отзывы после обучения.
- Адаптивные страницы авторизации со слайдером из четырёх изображений.
- Справочники курсов, оплаты и статусов заявок.
- Хеширование и проверка паролей.
- Подписанные сессии в cookie на один час и защита адресов `/admin/*`.
- Модели пользователей и заявок, миграции PostgreSQL и создание администратора.
- Набор компонентов интерфейса.

Перенесены четыре новых коммита до `c5fb3be9d96e3e889dafe0d80850fb1349d4fa5d`. Страница `/admin` в исходном репозитории пока отсутствует. Учебные материалы сохранены в `docs/reference`.

## Запуск

Понадобятся Node.js 20.19+ (либо поддерживаемая Prisma версия 22/24) и PostgreSQL.

```bash
cp .env.example .env
```

Укажите `DATABASE_URL` в `.env`. Сгенерируйте `SESSION_SECRET` командой ниже и запишите результат в `.env`:

```bash
node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"
npm ci
npm run db:deploy
npm run db:seed
npm run dev
```

Открыть: [localhost:3000](http://localhost:3000).

`npm ci` автоматически генерирует Prisma-клиент. Для повторной генерации после изменения схемы используйте `npm run db:generate`, для создания новой миграции — `npm run db:migrate`.

Сид создаёт учебного администратора `Admin / KorokNET`. Повторный запуск сохраняет существующую учётную запись.

## Проверки

```bash
npm run lint
npm run typecheck
npm test
npm run build
```

Сборка загружает шрифт Inter через `next/font/google`, поэтому для неё нужен доступ к Google Fonts и настроенный `DATABASE_URL`.

Для интеграционной проверки задайте `DATABASE_URL` отдельной тестовой базы и `SESSION_SECRET` в окружении. После применения миграций и сборки выполните `npm run test:integration`. Проверка создаёт пользователя и заявку, проверяет сервисы и HTTP-маршруты, затем удаляет свои записи. Локальный сервер на порту 3116 запускается и останавливается автоматически; порт можно изменить через `PORTAL_TEST_PORT`.

Результаты проверок — в [docs/verification.md](docs/verification.md).

Имена `page.tsx`, `layout.tsx`, `proxy.ts`, экспорты `metadata` и `config` сохранены, поскольку их использует Next.js. Схема таблиц, значения перечислений, содержимое миграций и параметры JWT совместимы с исходным проектом.
